# Technical Architecture (100% Zero-Budget Stack)

## 4-Layer Serverless Pipeline ($0.00 Operating Cost)
1. **Ingestion & UI Layer (Vercel Free / GitHub Pages):** Next.js/React Command Center + Pramana Live WebRTC Voice/Screen Widget.
2. **Perception & Triage Layer (Google AI Studio Free API):**
   - Gemini Live: Real-time voice + screen bug capture.
   - Gemini Omni: Visual DOM comprehension & layout-shift detection.
   - Gemma: High-speed, zero-cost HAR network & console log filtering.
3. **Agentic Orchestration & Self-Healing Layer:**
   - Google Antigravity: Repository AST dependency mapping & code patch generation.
   - Google Agent Skills: Modular execution primitives (`BrowserSandboxSkill`, `TraceCorrelatorSkill`, `GitPatchSkill`).
   - Google AI Studio: Strict JSON schema enforcement.
   - Nano Banana & Lyria: Visual UI diff synthesis & accessible audio cues.
4. **Zero-Cost Compute & Storage Layer:**
   - Sandbox Runner: Stateless Playwright Docker container on Hugging Face Spaces (Free 16GB RAM) / GitHub Actions.
   - State & Telemetry: Firebase Spark Free Tier (Firestore) / Local JSON store (Container-ready for Cloud Run scale-out).

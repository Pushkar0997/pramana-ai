# Project Brief: Pramana AI (by Team Vimarsha)

## 1. Core Thesis
**Pramana** (Sanskrit: *Verifiable Proof*) is a Zero-Cost, Autonomous Multimodal QA, Conversion-Leakage & Self-Healing Engineering Agent. Users paste any live website URL; Pramana visually navigates the user journey like a human, detects functional/UI/localization bugs that kill revenue, synthesizes a visual UI patch, and opens a verified GitHub Pull Request in under 60 seconds.

## 2. Target Wedge
- **Global B2B SaaS & FinTechs:** Replace brittle Playwright/Cypress CSS-selector tests and unreproducible customer bug tickets.
- **Indian D2C & ONDC Platforms:** Catch mobile viewport overlaps, 4G/UPI callback timeouts, and vernacular (Hindi/Marathi) text overflows.

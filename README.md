# Pramana AI
> **Verifiable Proof. Autonomous Resolution.**
> *Built by **Team Vimarsha** for Startup Buildathon India 2026*

**Pramana AI** is an Autonomous Multimodal QA, Conversion-Leakage & Self-Healing Engineering Agent. Paste any live web URL—Pramana visually navigates the application like a human user, detects revenue-leaking UI/network/localization bugs, previews a visual fix, and opens a ready-to-merge GitHub Pull Request in under 60 seconds.
